
# ABA Progress Graph Builder v3

## Improvements
- More robust goal detection from pasted treatment-plan rows
- Handles parent/caregiver goals
- Handles skill-acquisition and behavior-reduction goals
- Editable review table before graphing
- **Start Date can be changed independently for every program**
- One visible date label for every data point
- ZIP download of all graphs

## Updating your existing Streamlit app
1. Unzip this package.
2. Replace your repository's `app.py` with the new `app.py`.
3. Replace `requirements.txt`.
4. Commit the changes in GitHub.
5. Streamlit Cloud should redeploy automatically.
